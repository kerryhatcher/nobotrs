# Abstract

We introduce an abstract class of weight functions and define the associated so-called “weighted $W^{1,p}$-space” via Sobolev traces together with a quadratic form in its dual space which generalizes Dirichlet's principle to metric measure spaces $(X,\nu)$. These weighted spaces contain the classical ones (that are obtained as special cases) and admit certain approximation properties w.r.t.~the weight function. The main result characterises all measurable functions that lie inside these weighted spaces such that it contains essentially all measurable functions that satisfy our Dirichlet energy estimates in a suitable weak notion. As consequences we prove Lipschitz type approximations as well as an improved version of the lower semicontinuity theorem and also improve the embedding inequality in terms of Sobolev type norms whereby it turns into an equivalence. We finally present examples how our results compare to previous versions by applying them to geometric functional analysis and harmonic maps as one main application area for future work. Finally, further applications will be given to Riemannian manifolds under natural assumptions like doubling and geometric measure distance finiteness or if they possess sufficiently many cutpoints.
