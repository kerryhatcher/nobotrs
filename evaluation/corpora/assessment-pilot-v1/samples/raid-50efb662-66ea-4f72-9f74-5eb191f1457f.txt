> A set of vertices $S$ in a graph $G$ is called a 2-conversion set if $G-S$ has a perfect matching and $G-S$ has a perfect matching after removing any two vertices from $S$. A set $S$ is called irreversible if $S$ is a 2-conversion set but $S-v$ is not a 2-conversion set for any $v\in S$. In this paper, we prove that every graph of maximum degree at most 3 has an irreversible 2-conversion set.
