> We study the following game played on a graph G. Two players, Alice and Bob, alternately choose vertices of G. Alice wins if the set of vertices chosen by her is connected, and Bob wins otherwise. We show that if G is a planar graph with maximum degree Δ, then the game is determined and Alice has a winning strategy if and only if Δ ≥ 3. We also show that if G is a graph with maximum degree Δ, then the game is determined and Alice has a winning strategy if and only if Δ ≥ 3 and G is not a subdivision of K_{3,3}.
