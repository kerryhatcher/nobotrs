> We present a method for detecting missing method calls as violations of the majority rule. The method is based on the observation that the majority rule is a special case of the majority vote rule, which is a well-known method for detecting missing method calls. The method is implemented in the Java programming language and is used to detect missing method calls in a large Java program. The results show that the method is able to detect a large number of missing method calls, and that the majority rule is a good way to detect missing method calls.
