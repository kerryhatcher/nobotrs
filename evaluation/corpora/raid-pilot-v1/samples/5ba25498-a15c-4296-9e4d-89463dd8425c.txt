In this paper, we propose a novel approach for weakly supervised image segmentation using inter-extreme points geodesics. Our method leverages the geometric properties of inter-extreme points to learn a mapping between the input image and a set of labeled images. We use this mapping to generate segmentation masks for the input image without requiring any explicit supervision. Our approach is based on the idea of using geodesics to find the shortest path between two points in a manifold. We extend this idea to the context of image segmentation by defining a manifold of labeled images and finding the shortest path between the input image and a set of labeled images. We use this path to generate a segmentation mask for the input image. Our approach is weakly supervised, meaning that we only require a small number of labeled images to generate accurate segmentation masks. We evaluate our approach on several benchmark datasets and show that it outperforms state-of-the-art methods in terms of accuracy and speed.
