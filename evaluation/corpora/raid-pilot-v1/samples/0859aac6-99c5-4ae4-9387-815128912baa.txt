The purpose of this paper is to present an efficient and generic interactive segmentation framework that can be used to correct mispredictions during clinical evaluation of medical images. The framework is designed to be flexible and adaptable to different types of medical images, allowing it to be used across a wide range of applications. The framework uses a combination of machine learning algorithms and interactive user input to improve the accuracy of image segmentation. The paper presents the framework in detail, including the algorithms used, the user interface, and the evaluation results. The results show that the framework is able to significantly improve the accuracy of image segmentation, and that it is a valuable tool for clinical evaluation of medical images.
