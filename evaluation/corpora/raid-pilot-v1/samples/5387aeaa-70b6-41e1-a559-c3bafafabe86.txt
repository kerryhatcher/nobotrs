Input and output imbalance is a common problem faced by many multi-organ segmentation tasks. This can occur when some organs are frequently occluded or have lower contrast than others, making it more difficult to accurately identify them in images. In this study, we propose a new loss function called combo loss that addresses both input and output imbalance. Combo loss is designed to incorporate feedback from both input and output branches of a typical encoder-decoder model for multi-organ segmentation. We demonstrate that our proposed approach significantly improves performance on several benchmark datasets, demonstrating its effectiveness for handling input and output imbalance in challenging multi-organ segmentation problems.
