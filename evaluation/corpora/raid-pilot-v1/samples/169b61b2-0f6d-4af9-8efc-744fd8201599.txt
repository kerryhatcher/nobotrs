The paper presents an unsupervised semantic image segmentation method that utilizes Stylegan and CLIP to generate high-quality segmentation masks. The proposed method first generates a set of style-specific masks using Stylegan, which are then used as input to the CLIP model to generate semantic segmentation masks. The resulting method is able to generate accurate and high-quality segmentation masks without the need for labeled data, making it a valuable tool for applications where labeled data is scarce or expensive to obtain. The paper demonstrates the effectiveness of the proposed method on several benchmark datasets and shows that it is able to generate segmentation masks that are comparable to those generated using supervised methods.
