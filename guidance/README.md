# Guidance authoring

`guidance.json` is the canonical rule registry; `brief.md` is embedded by the loader. Each emitted editorial rule maps to exactly one entry. Category determines leverage: content 1, structure 2, rhythm 3, punctuation and formatting 4, vocabulary 5. Serialized leverage must agree with the category.

Explain reader impact, a possible edit and a legitimate exception. Examples must retain attribution, negation, modality, numbers and meaning; questions must remain visibly unresolved. Never advise fabricated detail, deliberate mistakes or detector-score optimization.

Sources record heuristic provenance, not proof of editorial benefit. The practical field-guide section and archived drafting instructions informed these prompts after removing fabrication and evasion advice. Structural thresholds are experimental and unvalidated. `time_bound` marks vocabulary observations that may change with model eras; false does not establish durability. Validation belongs in separate evaluation reports.
