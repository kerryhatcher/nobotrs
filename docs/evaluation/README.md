# Evaluation protocol

Run `python3 scripts/evaluate.py --binary target/release/nobotrs --manifest tests/fixtures/evaluation/manifest.json --output /tmp/results.json --check docs/evaluation/ci-baseline.json` after building. This reproduces a reusable behavior baseline. Fixtures are synthetic and have unknown authorship labels. Their pass rate must never be reported as detector precision or accuracy.

For a licensed authorship corpus, use the same manifest schema with `label` equal to `human` or `generated`, a verifiable provenance record, source grouping, slice, and split (`development`, `validation`, or `independent-test`). Group sources and near-duplicates before splitting. The runner rejects exact normalized duplicates/source groups across splits. Near-duplicate review remains a corpus-curation requirement, not a guarantee from this exact-hash check. Record edited/mixed texts without forcing binary labels when attribution is unreliable.

Use development data for feature work and validation data for choosing thresholds. `--split validation --sweep-quorum 1 2 3` evaluates quorum candidates from cached family contributions without rerunning extraction. The output stores raw metrics, coverage/abstentions, confusion matrix, precision, recall, F1, false-positive rate, Wilson sampling intervals, runtime, and slice counts. Empty denominators are null. No AUC is produced without a meaningful continuous ensemble score.

Before an independent run, freeze the exact configuration bytes and release criteria. Pass `--split independent-test --config frozen.json --release-access-record access.json`. The access file must contain `status: "frozen-unopened"` and `configuration_sha256`. Access is recorded before running, and further access is rejected. Freeze a named corpus revision and the release criteria in the record as well. If results inform any revision, retire that test set into selection data, explain the decision, and obtain fresh independent data; do not reset the access marker to iterate toward passing.

No licensed, independently held-out authorship corpus was supplied with this repository. The evaluated-release gate remains open. There are no independently measured accuracy, false-positive, or calibrated probability claims. The current default thresholds are inherited uncalibrated heuristics; no new voting signals were added. Release criteria require a curated corpus covering technical/informal/formal writing, document lengths, generators, non-native English, edited/mixed origin, multilingual text, and perturbations, with slice counts and sampling uncertainty reviewed before publishing a performance claim.
